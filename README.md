## 📋 User Groups

|---------|------|
| 🌐 Sito Web | [juggenova.it](https://juggenova.it) |
| 💻 GitHub | [github.com/jug-genova](https://github.com/jug-genova) |
| 💼 LinkedIn | [JUG Genova](https://www.linkedin.com/company/jug-genova) |
| 💬 Telegram | [@juggenova](https://t.me/juggenova) |

**Attività:** Incontri con presentazioni su Java e JVM · Gruppo di discussione online · Corsi e workshop · Eventi sociali e networking

## 🚀 Perché Partecipare

- **Networking** — Incontra professionisti, studenti e appassionati del settore IT
- **Formazione** — Partecipa a talk, workshop e corsi gratuiti su tecnologie all'avanguardia
- **Open Source** — Contribuisci a progetti open source e scopri nuovi framework
- **Carriera** — Scopri opportunità lavorative e costruisci la tua reputazione professionale

> 💡 Tutti i gruppi sono **gratuiti** e aperti a chiunque: professionisti, studenti, appassionati.
